🔴 FFH4x VIP — Android

Aplicativo Android desenvolvido em Kotlin para gerenciamento de perfis de sensibilidade do Free Fire.

📱 Funcionalidades

- Interface escura com detalhes vermelhos.
- Ajustes de valores de referência:
  - Geral
  - Ponto vermelho
  - Mira 2x
  - Mira 4x
  - AWM / Sniper
- Salvar perfis no aparelho.
- Carregar perfis salvos.
- Restaurar valores padrão.
- Atalhos para abrir Free Fire e Free Fire MAX.

🛠️ Tecnologias

- Kotlin
- Android Studio
- Gradle
- Android SDK 35

📲 Compatibilidade

Android 6.0 (API 23) ou superior.

🔧 Como gerar o APK

1. Baixe e extraia o projeto ZIP.
2. Abra a pasta no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Acesse Build > Build APK(s).
5. Localize o APK gerado em "app/build/outputs/apk/debug/".

⚠️ Aviso

O aplicativo é um painel auxiliar de configurações. Não modifica arquivos do Free Fire, não injeta código e não oferece mira automática.

Os valores devem ser aplicados manualmente nas configurações do jogo.
